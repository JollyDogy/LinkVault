# LinkVault - Менеджер ссылок

LinkVault - веб-приложение для сохранения, организации и управления интернет-ссылками. Оно позволяет создавать собственную библиотеку закладок, распределять ссылки по категориям, добавлять их в избранное и быстро находить нужные ресурсы.

## Возможности

- Добавление ссылок - сохранение названия, URL, описания и категории.
- Редактирование - изменение информации о сохранённых ссылках.
- Удаление - удаление ненужных ссылок.
- Категории - группировка ссылок по тематическим разделам.
- Создание категорий - создание собственных категорий.
- Поиск - поиск по названию и адресу сайта.
- Избранное - возможность отмечать важные ссылки.
- Локальное сохранение - данные сохраняются в браузере с помощью LocalStorage.

## Технологии

- HTML5 - структура приложения.
- CSS3 - оформление и адаптивный интерфейс.
- JavaScript (ES6+) - логика приложения и взаимодействие с пользователем.
- DOM API - динамическое создание, изменение и удаление HTML-элементов.
- LocalStorage - локальное хранение данных.
- ES Modules - разделение JavaScript-кода на отдельные модули.

### Назначение файлов

|---|---|

| `style.css` | Стили и оформление |

| `ui.js` | Создание и обновление элементов DOM |
| `storage.js` | Работа с LocalStorage |
| `links.js` | Логика управления ссылками |
| `categories.js` | Управление категориями |


## Хранение данных

Все пользовательские данные сохраняются локально в браузере с использованием LocalStorage. Регистрация и подключение к серверу не требуются.
